CAMPAIGN BUILDER — the downloadable pack
=========================================

Two files, both replacing what is there:

    src/CampaignBuilder.jsx
    netlify/functions/campaign.js

Add file -> Upload files, drag in BOTH folders (src and netlify),
commit. No new environment variables. No hand edits.

This includes everything from the last update as well, so if that one
did not go in, this covers it.


THE CAMPAIGN PACK
-----------------
One button: "Download campaign pack". It produces a single
self-contained HTML file the SBU leader can open, read, forward, or
print straight to PDF. No dependencies, nothing to install.

Inside:

  - A branded cover with the unit, goal, timeframe, budget, audience,
    who prepared it and when
  - What the data said going in, so the plan can be judged against
    the evidence it was built on
  - The whole plan typeset properly -- tables, schedules, copy
  - Every email RENDERED, not shown as code. Each one sits in a live
    preview with its subject, preheader and send timing above it,
    a Copy HTML button, a Download .html button, and the source
    tucked behind a "View source" toggle

Print to PDF and the buttons and source blocks drop out, leaving a
clean document with the emails still rendered.

There is still a Markdown button next to it if you want the raw text.


EMAILS ARE A SEQUENCE NOW
--------------------------
The plan used to end with one email. It now writes the full flow the
channel plan calls for -- typically two or three -- each with its own
label, subject, preheader, send timing, a line on who gets it and
why, and complete HTML. They are written to follow each other rather
than repeat.

Every email: table layout, inline styles, 600px, brand palette,
pill CTA, hidden preheader span, unsubscribe line, %%FirstName%%
merge fields, and the SFMC open tracking pixel before </body>.


LINKEDIN POSTS ARE COMPLETE CAPTIONS
-------------------------------------
Three posts, one per touch in the sequence, each a full caption ready
to paste: opening line, body with line breaks, a clear ask, and
hashtags. The prompt explicitly forbids placeholders.

Plus two organic company-page posts.


TOKEN LIMIT
-----------
Raised again, to 24,000, to fit a full email sequence. Cost per run
is now roughly 18 cents. At $25 a month that is around 140 runs.


AN EXAMPLE
----------
example-campaign-pack.html, sent alongside this, is a real pack
produced by this build. Open it in a browser to see what an SBU
leader receives. The content is a test plan rather than a real one,
but the format is exactly what you will get.
