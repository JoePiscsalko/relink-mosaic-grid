WHAT WAS WRONG
--------------
My fault, and a silly one.

When I rewrote the prompt to be strategy-led rather than keyword-led,
the replacement left a doubled backtick where the prompt text ends:

    ...rather than repeating it.``;

That closed the prompt string and immediately opened a new one, which
then ran on until it hit the next backtick 60 lines further down. The
file stopped being valid JavaScript from that point.

Netlify could not parse it, so it fell back to loading the raw file as
CommonJS, which is why the crash page said "Cannot use import
statement outside a module" and pointed at line 1. That message was a
symptom. The real fault was one character.

It also explains the empty function log: the crash happened at module
load, before any of the code that logs ran.
